# LetYouEatMyNoodle Restaurant Website

A modern, responsive website for LetYouEatMyNoodle, a Malaysian noodle restaurant chain. This project showcases a complete restaurant website with various features including menu ordering, user authentication, and interactive elements.

## Features

### 1. Navigation and Layout
- Responsive header with navigation menu
- Modern and clean user interface
- Smooth scrolling and animations
- Interactive elements with hover effects

### 2. Menu System
- Comprehensive menu categories:
  - Set Meals
  - À la carte dishes
  - Side Dishes
  - Beverages
- Detailed item descriptions and pricing
- Easy-to-use ordering interface

### 3. User Features
- User authentication system
  - Login functionality
  - Registration with validation
  - Password recovery option
- Shopping cart functionality
- Order tracking
- Membership system

### 4. Content Sections
- Home page with featured dishes
- About Us section with company history
- Interactive image slider
- Promotional offers page
- Store locations and map
- Working hours
- Contact information

### 5. Additional Features
- Feedback form for customer reviews
- FAQ section
- Privacy policy
- Social media integration
- Background music (toggleable)
- NoodleBot chat assistant for customer support

### 6. Technical Features
- Responsive design for all devices
- Modern CSS animations and transitions
- Form validation
- Interactive UI elements
- Cross-browser compatibility

## Technologies Used
- HTML5
- CSS3
- JavaScript
- DialogFlow (for chatbot)
- SVG icons
- Google Maps integration

1. Clone the repository
2. Open `html/home.html` in your web browser
3. Navigate through the website using the menu bar

## About the Company
LetYouEatMyNoodle is a Malaysian noodle restaurant chain founded in 1996 in Sungai Petani, Kedah. Starting as a small local business under the name XiaMianGeiNiChi, it has grown into a successful chain with multiple locations across Malaysia, serving thousands of customers daily.
